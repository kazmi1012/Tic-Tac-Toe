# Python Terminal Games 🎮

A collection of classic terminal-based games built in Python.

## Games Included

### 1. TicTacToe
- 2-player game on the same keyboard
- enter your move through (1-9) number
- Full win detection across rows, columns, and diagonals
- Draw detection
## How to Run

1. Clone the repo
```bash
git clone https://github.com/kazmi1012/RockPaperScissors.git
```

2. Run any game
```bash
python tictactoe.py
